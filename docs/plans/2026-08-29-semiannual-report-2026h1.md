## 4. Pympress 故障根因

### 症状

旧双屏 PDF 中，第 3、5、11、15、16、17 页在 Pympress 左屏只剩标题或底部 block，表格主体消失；普通 PDF 同页完整，右侧讲稿缩略图也完整。

### 根因证据

- 问题已经存在于 Beamer 原生 `show notes on second screen=right` 生成的双宽 PDF，不是 Pympress 窗口缩放造成。
- 逐页像素检查显示旧版左屏在上述页面与普通版明显不同；其他大部分页面一致。
- 将相同 frame 单独编译时表格可以显示，说明内容本身和 LaTeX 语法没有损坏。
- 根因位于 Beamer/pgfpages 双屏模式复制 frame box 的路径：部分含表格/数组的页面在多 frame 文档中复制到左逻辑页时丢失主体盒子。

### 修复策略

不再信任 Beamer 原生双屏 PDF 的左逻辑页：

1. 普通版正常编译，作为唯一可信的左屏来源。
2. 原生双屏版只用于生成右侧讲稿页。
3. 使用 `scripts/build_pympress_dual_pdf.py` 将普通版原页放在左半屏，并裁取原生双屏版右半讲稿放在右半屏。
4. 自动渲染全部 17 页，逐页断言最终双屏左半与普通版像素一致。
5. 启动本机 Pympress 1.8.6，实际导航并截图检查用户点名的六页。
