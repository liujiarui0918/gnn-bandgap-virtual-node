## 一、论文定位（决定一切的前提）

这**不是**一篇"我提出了更强的模型"的论文，而是：

> 一篇用严格统计证明"**复杂的全局机制不可靠、简单的才可迁移，而且模型排名会被数据源标签悄悄改写**"的方法学论文。

三个核心贡献，按原创性排序：

| # | 贡献                                            | 原创性   | 说明                                                                                                                                                                                             |
| - | ----------------------------------------------- | -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 1 | **跨源标签一致性审计**（structure-first） | ⭐⭐⭐⭐ | 先配结构、再查标签。92,787 条结构匹配记录中仍有 3,142 + 3,046 条金属/非金属互相冲突、1,121 条同类差 >1 eV。**"结构对应 ≠ 标签一致"是真正新的、对社区有用的发现。**                        |
| 2 | **阴性结果 + 统计严谨性**                 | ⭐⭐⭐   | paired bootstrap (B=10,000)、3 seeds × 6 models × 2 sources、cross-label 2×2、β 与 min_scale 敏感性扫描、专为弱 baseline 做的 tuning probe。**严谨度显著高于材料 ML 的平均发表水平。** |
| 3 | **架构结论（VN + Huber）**                | ⭐⭐     | 虚拟节点（Gilmer 2017 / Graphormer / Cai 2023 / Southern 2024 / Okabe 2024）和 Huber loss 都是成熟组件，组合属增量。                                                                             |

**关键认知**：贡献 1 和 2 是你的资产，贡献 3 是你的负债。**任何以贡献 3 为卖点的投稿都会碰壁；以贡献 1+2 为卖点的投稿则有明确的期刊愿意接。**

## 二、决定档次的四个硬约束（必须正视）

### ① 【最严重】Baseline 存在预算截断，绝对性能不具竞争力

实测 `results/*/comparison_summary.csv`：

| 运行         | T2 ALIGNN`best_epoch / epochs_ran` |
| ------------ | ------------------------------------ |
| MP seed 42   | **50 / 50** ← 撞边界          |
| MP seed 1042 | 48 / 50                              |
| MP seed 2042 | 49 / 50                              |
| HZW seed 42  | **50 / 50** ← 撞边界          |

T8、T9 同为 50/50。几乎所有 ALIGNN 族模型的 best epoch 都落在 45–50 区间。

**最佳验证轮次撞在预算边界 = 模型停止时仍在改善 = 欠训练。**

正文 4.3 节这句话逻辑写反了：

> "every model attains its best validation epoch in the last fifth of the budget (epochs 41–50), **so no reported test metric comes from an under-trained** … run"

配合 ALIGNN baseline = 0.240 eV（而 ALIGNN 在公开 `matbench_mp_gap` 上约 0.186 eV），**这两件事凑在一起，npj CM / JCIM 级别的审稿人第一轮必然点出。**

> 讲公道话：你的**相对结论不受影响**（同预算、同 split、3 种子、有 CI，T2→T4→T7 站得住）。但它封死了"绝对竞争力"这条叙事，而那正是高档期刊的门槛。

### ② 没有标准 benchmark 锚定

全文无 `matbench_mp_gap` / JARVIS 数字。审稿人无法把 0.223 eV 放进任何已知坐标系。这是高档期刊最常见的拒稿理由之一。

### ③ HZW 专有数据承载了你一半的论点

"跨源标签一致性"最有原创性，却建立在不可再分发的数据上。你提供了 MP id 列表（很好），**但跨源比较本身第三方无法复现**。npj CM / Scientific Data 的 data availability 政策会卡这条。

### ④ 次要但会被问到

- 只做一个属性（带隙），泛化性主张受限
- SOTA 架构（Matformer / ComFormer / PotNet / coGN）只在 related work 引用、**未实跑**
- M3GNet baseline 偏弱（0.29 vs ALIGNN 0.24），虽已用三个 probe 辩护，仍会被质疑
- 单作者、无机构署名（非硬伤，但顶刊编辑会注意）
- **内部不一致**：补充材料 Table S16 写 "T2 ALIGNN (reference) — Best/ran 48/50"，与 mainline 记录 50/50 矛盾，投稿前务必核对

## 八、一句话总结

> **你的论文最大的价值不在模型，而在"你证明了这个领域普遍存在的单种子、单数据源评估会得出错误结论"。**
